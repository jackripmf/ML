# car_price_predict

Предсказание рыночной стоимости автомобиля по его характеристикам с помощью линейной регрессии.

## Задача

Предсказать цену автомобиля (MSRP) на основе технических характеристик: объём двигателя, год выпуска, тип топлива, привод, марка, стиль кузова и других признаков.

## Данные

- **Источник:** `ds/data.csv`
- **Размер:** 11 914 строк, 16 признаков
- **Целевая переменная:** `msrp` (рекомендованная розничная цена)
- **Ключевые признаки:** год, engine_hp, engine_cylinders, driven_wheels, vehicle_style, make

## Модель

### Версия 1: Ручная линейная регрессия (`car_price.ipynb`)

- Нормальное уравнение для поиска весов
- L2 регуляризация (Ridge) для борьбы с мультиколлинеарностью
- `np.linalg.pinv` вместо `inv` для устойчивости к сингулярным матрицам

### Версия 2: sklearn (`car_price_sklearn.ipynb`)

- `LinearRegression` и `Ridge` из sklearn
- Подбор `alpha` по validation: `[0, 0.001, 0.01, 0.1, 1, 10]`

### Техники preprocessing

- One-Hot Encoding (`pd.get_dummies`) для категориальных признаков
- `np.log1p` трансформация целевой переменной (цены имеют правое хвостое распределение)
- Заполнение пропусков средним значением
- Разделение данных 60/20/20 (train/val/test)
