# Student Performance — Предсказание оценок учеников

Четвёртый проект из книги «Машинное обучение: портфолио реальных проектов» (Григорьев).

## Задача

Предсказать **итоговую оценку ученика (G3, 0-20)** по демографическим данным, семейному положению, условиям обучения и стилю жизни.

## Данные

- Два CSV-файла: `student-mat.csv` (395 строк) и `student-por.csv` (649 строк)
- 30 входных признаков: возраст, образование родителей, работа родителей, школа, время на дорогу, время на учёбу, неудачи, поддержка школы/семьи, оплачиваемые занятия, активности, сад, высшее образование, интернет, романтика, отношения в семье, свободное время, прогулки, алкоголь, здоровье, пропуски
- Целевая переменная: G3 (итоговая оценка за семестр)

## Модель

- **LinearRegression** (sklearn)
- One-Hot Encoding для категориальных признаков
- Ручное разбиение 60/20/20 с shuffle

## Результаты

| Метрика | Значение |
|---------|----------|
| MAE | 2.81 |
| RMSE | 3.73 |
| R² | 0.09 |

R² низкий, потому что из X убраны G1 и G2 (сильные предикторы — это оценки за середину семестра). Без них демография и стиль жизни — слабые предикторы итоговых оценок. Это честный результат.

## Ключевые уроки

1. **Data Leakage** — если целевая переменная (G3) попадает в X, RMSE ≈ 0. Всегда проверяй.
2. **Shuffle обязателен** — без него train = математики, test = португальцы.
3. **R² ≈ 0.10 — это не провал** — слабые признаки дают низкий R², но модель работает честно.
